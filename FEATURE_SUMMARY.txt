WHAT WAS BUILT
================================================================================

A new method "setQueryData()" has been added to the HijackTable class that:
- Retrieves filtered data based on SQL-like query conditions
- Returns a JavaScript array of matching records
- Does NOT modify the table display or state
- Supports complex queries with AND, OR, parentheses, and comparisons

QUERY SYNTAX
================================================================================

Comparison Operators:
  = (equals)
  > (greater than)
  < (less than)
  >= (greater or equal)
  <= (less or equal)
  != (not equal)

Logical Operators:
  AND (both conditions true)
  OR (either condition true)
  () (parentheses for grouping)

Examples:
  "work = 'Engineer'"
  "age > 25"
  "work = 'Engineer' AND age > 25"
  "work = 'Engineer' OR work = 'Doctor'"
  "(work = 'Engineer' OR work = 'Doctor') AND age >= 30"
