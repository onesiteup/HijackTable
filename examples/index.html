HijackTable Examples

Each feature of hijack-table.js has its own page. Every page contains a live demo and its documentation.

1. Basic table
Create a table with init(). 2. Layout function
Build each row with the layout function and header names from dataSelection. 3. Table styling
Set the element, class, style and id of the wrapper, head and body. 4. Update data
Replace rows with updateData() while keeping the table structure. 5. Filter the table (setQueryTable)
Filter the displayed rows with SQL-like conditions. 6. Get query data (getQueryData)
Get matching rows as an array without changing the display. 7. Query operators
Comparison, contains, in, AND, OR and parentheses. 8. Search
Search all columns or selected columns, optionally inside a query filter. 9. Clear filters
Remove the active query with clearFilters(). 10. Data and statistics
Read data with getData(), getFilteredData() and getStats(). 11. Responsive layouts
Switch between table and card layouts with layoutBreakPoints.
