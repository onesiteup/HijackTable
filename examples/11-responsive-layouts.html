11. Responsive layouts

What it does

The responsive object holds one layout for each screen size. When the table is built, the library checks layoutBreakPoints and uses the first layout whose media query matches the window. When the window is resized across a breakpoint, the table is built again with the other layout.

Config keys

KeyDescription
layoutBreakPointsObject of media queries, e.g. mobile: "max-width: 768px;". The key must match a key in responsive. Queries are checked in the order they are defined. The trailing ; is optional.
mainThe outer element: element, id, class, style.
dataSelectionShared fields: { id, name }. Table layouts use name for the header.
responsiveOne entry per breakpoint key. Each entry has type ("table" or "card"), wrapper, wrapperHead, wrapperBody and layout.

If no breakpoint matches, the first layout in responsive is used. If layoutBreakPoints is not set, the first layout is always used.

Active layout:

Code

const config = {
    layoutBreakPoints: {
        mobile: "max-width: 768px;",
        desktop: "min-width: 769px;"
    },
    main: {
        element: "div",
        class: "responsive",
        style: "max-height: calc(100vh - 175px); overflow-y: auto;"
    },
    dataSelection: [
        { id: "sno", name: "S No" },
        { id: "age", name: "Age" },
        { id: "height", name: "Height" },
        { id: "work", name: "Work" }
    ],
    responsive: {
        desktop: {
            type: "table",
            wrapper: { element: "table", class: "table table-bordered", style: "width: 100%;" },
            wrapperHead: { element: "thead", class: "sticky-top", style: "background: white;" },
            wrapperBody: { element: "tbody", class: "" },
            layout: function () {
                const badge = this.age <= 40
                    ? '<span class="badge bg-success">Young</span>'
                    : '<span class="badge bg-danger">Old</span>';

                return `<tr><td>${this.sno}</td><td>${this.age} ${badge}</td><td>${this.height}</td><td>${this.work}</td></tr>`;
            }
        },
        mobile: {
            type: "card",
            wrapper: { element: "div", class: "mobile-list", style: "display: grid; gap: 10px;" },
            wrapperHead: { element: "div", class: "d-none", style: "" },
            wrapperBody: { element: "ul", class: "mobile-list-body", style: "" },
            layout: function () {
                return `<li class="card mb-2"><div class="card-body"><div><strong>${this.sno}.</strong> ${this.work}</div><div>Age: ${this.age}</div><div>Height: ${this.height}</div></div></li>`;
            }
        }
    }
};

const table = new HijackTable();
table.init('#responsive-table', data, config);

Notes

  • Put layoutBreakPoints keys and responsive keys with the same names.
  • Use type: "table" to build the header from dataSelection. type: "card" does not need header cells, so its wrapperHead can be hidden with d-none.
  • Resizing the window rebuilds the table only when the active layout changes.
