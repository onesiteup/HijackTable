10. Data and statistics

What it does

These methods let you read the table's state without changing it.

Methods

MethodReturns
getData()All rows you passed to init() or updateData()
getFilteredData()The rows currently shown (after a query or search)
getStats()An object with totalRows, filteredRows and columns

Live demo


        

    


    
Code


const all = table.getData();               // every row
const shown = table.getFilteredData();     // rows on screen

const stats = table.getStats();
// { totalRows: 10, filteredRows: 2, columns: 4 }


    
Notes

    
    
        
  • Changing the returned arrays does not update the table. Use setQueryTable(), search() or updateData() for that.
