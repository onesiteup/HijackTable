5. Filter the table (setQueryTable)

What it does

setQueryTable(queryString) filters the rows shown in the table using a SQL-like WHERE condition. The query is stored, so it is applied again after updateData() and used by search().

Signature

table.setQueryTable(queryString)
  • queryString: a condition such as "work = 'Engineer' AND age > 25". The WHERE keyword is optional.
  • An empty string (or null) clears the filter and shows all rows.
  • Returns the table object, so calls can be chained.

Live demo

Try: work = 'Doctor', age > 28, work = 'Doctor' OR work = 'Nurse'

Code

table.setQueryTable("work = 'Engineer' AND age <= 40");

// Show all rows again
table.setQueryTable("");

Notes

  • String values need single quotes: work = 'Engineer'. Numbers do not: age = 25.
  • The older setFilter() method is deprecated. Use setQueryTable() instead.
  • To get the matching rows without changing the table, use getQueryData() (see example 6).
