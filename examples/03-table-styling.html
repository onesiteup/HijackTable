3. Table styling

What it does

The config object sets the element, id, class and style of each part of the table. The library creates the elements for you, so you choose the tag names.

Config keys

KeyElement it styles
mainThe outer wrapper, created inside the container you pass to init() (default tag div)
wrapperThe element that holds the head and body, e.g. table
wrapperHeadThe head element, e.g. thead
wrapperBodyThe body element that receives the rows, e.g. tbody

Each key accepts element, id, class and style (CSS string). Only wrapper and wrapperBody are needed for a simple layout; the head is optional.

Live demo

Code

const config = {
    main: { element: "div", id: "styled-wrapper", class: "table-responsive", style: "max-height: 300px; overflow-y: auto;" },
    dataSelection: [
        { id: "sno", name: "S No" },
        { id: "name", name: "Name" },
        { id: "age", name: "Age" },
        { id: "work", name: "Work" }
    ],
    responsive: {
        desktop: {
            type: "table",
            wrapper: { element: "table", class: "table table-striped table-bordered", style: "width: 100%;" },
            wrapperHead: { element: "thead", class: "table-dark sticky-top" },
            wrapperBody: { element: "tbody", id: "styled-body" },
            layout: function () {
                return `${this.sno}${this.name}${this.age}${this.work}`;
            }
        }
    }
};

table.init('#styled-table', data, config);

Notes

  • Bootstrap classes work directly, because the library only sets the class names you provide.
  • Setting main.style with max-height and overflow-y makes the table scroll while the header stays visible with sticky-top.
