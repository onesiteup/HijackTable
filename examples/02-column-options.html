2. Layout function

What it does

Each row is turned into HTML by the layout function of a responsive layout. Inside the function, this is the current row, so you can read any field and add conditional markup. Header names come from dataSelection.

Layout properties

PropertyDescription
dataSelectionArray of { id, name }. id is the row property, name is the header text.
type"table" builds the header cells from dataSelection. "card" builds no header.
layoutA function that runs once per row with this set to that row. It returns the HTML for one row (a <tr> for tables, an <li> for cards).

Live demo

Ages 40 and under show Young, and older ages show Old. The badge is built inside layout from this.age.

Code

const config = {
    dataSelection: [
        { id: "sno", name: "S No" },
        { id: "name", name: "Name" },
        { id: "age", name: "Age" },
        { id: "work", name: "Work" }
    ],
    responsive: {
        desktop: {
            type: "table",
            wrapper: { element: "table", class: "table table-bordered" },
            wrapperHead: { element: "thead" },
            wrapperBody: { element: "tbody" },
            layout: function () {
                const badge = this.age <= 40
                    ? '<span class="badge bg-success">Young</span>'
                    : '<span class="badge bg-danger">Old</span>';

                return `<tr><td>${this.sno}</td><td>${this.name}</td><td>${this.age} ${badge}</td><td>${this.work}</td></tr>`;
            }
        }
    }
};

table.init('#column-table', data, config);

Notes

  • Use function (), not an arrow function, for layout. An arrow function does not get this set to the row.
  • The returned string is inserted as HTML, so only return trusted content.
