9. Clear filters

What it does

clearFilters() removes the active query and shows all rows again. It also forgets the stored query, so later updateData() calls will not filter the rows.

Signature

table.clearFilters()
  • Returns the table object, so calls can be chained.
  • Clearing a filter with setQueryTable("") has the same effect.

Live demo

Code

table.setQueryTable("work = 'Engineer'");
console.log(table.getFilteredData().length);  // only engineers

table.clearFilters();
console.log(table.getFilteredData().length);  // all rows again

Notes

  • clearFilters() resets the stored query. setQueryTable("") also clears it.
  • The search box is not reset by this method. Clear your own input if you use one.
