8. Search

What it does

search(searchTerm, searchColumns) shows only the rows where a column contains the text (case-insensitive). If a query from setQueryTable() is active, the search runs inside those rows. An empty search brings back the query result, or all rows if there is no query.

Signature

table.search(searchTerm, searchColumns = null)
  • searchTerm: text to look for.
  • searchColumns: optional array of column ids, such as ["name", "work"]. If omitted, all columns are searched.

Live demo

Code

table.search("eng");                  // all columns
table.search("eng", ["work"]);        // only the work column
table.search("");                     // reset to query result or all rows

// Search inside a query
table.setQueryTable("age >= 25");
table.search("doc");

Notes

  • The search matches part of the text, so "eng" matches Engineer.
  • Search changes the rows shown on the table, the same as setQueryTable().
