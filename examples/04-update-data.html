4. Update data

What it does

updateData(newData) replaces the rows in the table body. The header and the table element stay in place. If a query is active, it is applied again to the new data.

Signature

table.updateData(newData)

Live demo

Code

function loadLargeData() {
    const newData = [];
    for (let i = 1; i <= 100; i++) {
        newData.push({ sno: i, name: "Person " + i, age: 20 + (i % 30), work: "Worker" });
    }
    table.updateData(newData);
}

Notes

  • Use updateData() instead of init() when you only change the rows. It keeps the table element and its configuration.
  • An active query from setQueryTable() is applied to the new rows automatically.
