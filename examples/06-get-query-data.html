6. Get query data (getQueryData)

What it does

getQueryData(queryString) returns an array of the rows that match the condition. It does not change the table on screen, and it does not store the query.

Signature

table.getQueryData(queryString) // returns Array
  • An empty string returns all rows.
  • The rows are the original objects from your data, so they can be exported, counted, or sent to an API.

Live demo

The table below always shows all rows. Only the results panel changes.


        

    


    
Code


const engineers = table.getQueryData("work = 'Engineer'");

console.log(engineers.length);  // number of matches
console.log(engineers[0]);      // first matching row object

// Use the result, for example to calculate an average
const avgAge = engineers.reduce((sum, r) => sum + r.age, 0) / engineers.length;


    
Notes

    
    
        
  • Use getQueryData() when you need data for code and setQueryTable() when you need to show the filter on the table.
    • 
        
  • If no rows match, the result is an empty array.
