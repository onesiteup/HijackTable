7. Query operators

What it does

Query strings support comparison operators, text and list matching, and logical AND / OR with parentheses. Operators are case-insensitive.

Supported operators

OperatorExampleMeaning
=age = 25Equals
!=work != 'Student'Not equal
>, >=age >= 25Greater than (or equal)
<, <=age <= 30Less than (or equal)
containsname contains 'an'Text contains the value (case-insensitive)
inwork in 'Doctor,Nurse'Value is one of the comma-separated list
ANDwork = 'Engineer' AND age > 25Both conditions are true
ORwork = 'Doctor' OR work = 'Nurse'Either condition is true
( )(work = 'Engineer' OR work = 'Doctor') AND age >= 25Groups conditions

Live demo

Each row runs a query with getQueryData() and shows the matching names. The table on the page is not changed.

QueryMatchesNames

Code

table.getQueryData("age = 25");
table.getQueryData("work != 'Student'");
table.getQueryData("age >= 25 AND age <= 30");
table.getQueryData("name contains 'an'");
table.getQueryData("work in 'Doctor,Nurse'");
table.getQueryData("(work = 'Engineer' OR work = 'Doctor') AND age >= 25");

Notes

  • Strings need single quotes (work = 'Engineer'). Numbers do not (age = 25).
  • WHERE at the start of the query is optional.
  • Compare with the numeric operators only when the field holds numbers.
