1. Basic table

What it does

init(container, data, config) creates the table inside a container and renders it. The dataSelection array in config decides the header names and fields, and responsive decides how each row is built.

Signature

table.init(container, data, config)
  • container: a CSS selector ('#my-table') or a DOM element.
  • data: an array of objects.
  • config: an object with dataSelection (the fields and header names) and responsive (the layout to build). See the other examples for the full options.

Live demo

Code

const table = new HijackTable();

const data = [
    { sno: 1, name: "Asha", age: 25, work: "Engineer" },
    { sno: 2, name: "Ben",  age: 30, work: "Doctor" }
];

const config = {
    dataSelection: [
        { id: "sno",  name: "S No" },
        { id: "name", name: "Name" },
        { id: "age",  name: "Age" },
        { id: "work", name: "Work" }
    ],
    responsive: {
        desktop: {
            type: "table",
            wrapper: { element: "table", class: "table table-bordered" },
            wrapperHead: { element: "thead" },
            wrapperBody: { element: "tbody" },
            layout: function () {
                return `${this.sno}${this.name}${this.age}${this.work}`;
            }
        }
    }
};

table.init('#basic-table', data, config);

Notes

  • dataSelection sets the header names (name) and the fields available to the layout.
  • With type: "table", the header row is built from dataSelection. Your layout function returns the body rows.
  • Rows are shown in the order of the data array.
